# Página temporal de studionomade.cl

Página de un solo archivo (fuentes e isotipo incrustados) que se muestra en
`studionomade.cl` mientras el sitio nuevo (`apps/web`) se publica en Vercel.

- Alojamiento: SiteGround, sitio `studionomade.cl`, `public_html/index.html`.
- Identidad: tokens y tipografías del design system (Cy Grotesk, Gotham, acentos de áreas).
- Se retira cuando el dominio raíz apunte al proyecto Vercel `studionomade-web`.
