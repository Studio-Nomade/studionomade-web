# Manual editorial

Roles activos: editor crea/edita; reviewer revisa; area_editor limita área; admin/superadmin administran; commercial gestiona leads; analyst solo consulta agregados. La allowlist, guards y RLS siempre aplican.

Flujo: crear borrador, completar slug/SEO/bloques/medios, verificar derechos y `authorization_granted`, previsualizar, solicitar revisión y publicar. Nunca subir secretos, PII ni material sin licencia. Los casos requieren portada, desafío, estrategia, resultado, área y medios optimizados. Embeds solo Vimeo/Behance autorizados; redes manuales se muestran como enlace/tarjeta. Prototipos requieren datos ficticios, noindex, versión y validación del paquete. Leads se consultan solo por personal autorizado; no copiar a hojas personales ni logs. Para retirar contenido, despublicar primero y conservar evidencia/auditoría.
