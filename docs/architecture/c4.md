# Arquitectura C4 inicial

## Nivel 1 — Contexto

```mermaid
C4Context
  title Ecosistema web Studio Nomade — contexto
  Person(visitor, "Visitante", "Consulta el sitio y Digital Lab")
  Person(editor, "Equipo Studio Nomade", "Administra contenido")
  System(web, "Ecosistema web", "Sitio público, Digital Lab y Web Admin")
  System_Ext(noma, "Noma", "Operación comercial existente; fuera de alcance")
  System_Ext(google, "Google", "Workspace y OAuth")
  Rel(visitor, web, "Navega")
  Rel(editor, web, "Administra")
  Rel(web, noma, "Integración futura mediante contratos")
  Rel(web, google, "Autenticación futura")
```

Noma se representa como sistema externo: M00 no lo crea, configura ni modifica.

```mermaid
C4Container

  Rel(admin, db, "API futura")
  Rel(web, noma, "Contrato futuro")

```

Las relaciones con Supabase y Noma son objetivos futuros, no implementaciones de M00.
